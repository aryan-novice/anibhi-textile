How to get an access key (one time)
  1. Open GitHub → New fine-grained token.
  2. Name it Anibhi admin and pick an expiry (up to 1 year).
  3. Under Repository access, choose Only select repositories and pick anibhi-textile.
  4. Under Permissions → Repository permissions, set Contents to Read and write.
  5. Click Generate token, copy it, and paste it above.
